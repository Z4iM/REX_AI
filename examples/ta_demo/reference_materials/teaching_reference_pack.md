## Question bank
Q1: What is sum([120,80,50])? Answer: 250. Q2: Why validate float input? Answer: invalid input must produce a clear error rather than crash. Q3: When should a function be used? Answer: to isolate and reuse a coherent operation. Practical question: implement a total function that rejects negative expenses.

## Assessment rubric
Correctness 50 points: totals and CSV round trip work. Validation 30 points: missing, nonnumeric and negative values handled clearly. Clarity 20 points: meaningful names, a short README and repeatable test steps. Passing demonstration threshold: 60 out of 100. This threshold is an authored fixture, not academy policy.

## Capstone specification
Build a local expense tracker with add, list and total commands. Use only fictional transactions. Persist a date, category and amount in CSV. Deliver source code, test inputs, expected totals and a README. Exclude authentication, payments and external personal data from this learning exercise.
