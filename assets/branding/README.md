# Andalusia Academy identity

The logo SVG is the unmodified official asset retrieved from https://andalusia-academy.com/images/logo/aha-colored-logo.svg on 2026-10-29. The favicon comes from https://andalusia-academy.com/favicon.ico. The identity manifest records the original logo checksum and source URLs.

The application uses the website's copper accent (#B07963), charcoal text (#212D30), white and warm neutral backgrounds with sans-serif typography. Document covers, burgundy banners, copper rules and pale overview cards use the academy portfolio document style.

Brand assets are stored locally so rendering does not depend on external requests. Logo content is not redrawn or substituted. No course facts, accreditation claims, contacts or partnership assertions are imported from the visual reference into generated records.
